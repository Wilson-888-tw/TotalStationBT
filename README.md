# 全站儀藍牙接收 App（TotalStationBT）

Android 應用程式，透過藍牙 SPP（Serial Port Profile）接收全站儀測量資料，自動解析並匯出 CSV。

---

## 支援格式

| 品牌 | 格式 | 說明 |
|------|------|------|
| Leica | GSI-8 / GSI-16 | 最常見格式，支援角度/距離/坐標 |
| Sokkia / Pentax | SDR33 | 量測記錄 (07TR) 及坐標記錄 (13CO) |
| Nikon | RAW | SS/SP 量測、CO 坐標記錄 |
| Topcon | GTS | HA=/VA=/SD= 鍵值格式 |
| 通用 | - | 逗號或空白分隔的數值 |

## 使用步驟

### 1. 全站儀端設定
1. 開啟全站儀藍牙功能（各品牌操作不同，參閱儀器手冊）
2. 設定通訊參數：
   - **波特率**：9600 或 38400（與儀器一致）
   - **資料位**：8-N-1
3. 將儀器設為「資料輸出」或「連線」模式

### 2. 手機配對
1. 前往系統設定 → 藍牙 → 掃描裝置
2. 找到全站儀（通常顯示型號名稱）→ 配對
3. 配對碼通常為 **0000** 或 **1234**

### 3. App 操作
1. 開啟 App，點擊右下角 **藍牙圖示** FAB
2. 從配對裝置清單選擇全站儀
3. 在儀器端執行量測或傳送資料
4. 資料即時顯示於畫面（綠色 = 解析成功，紅色 = 無法解析）
5. 點擊 **匯出 CSV** → 存至 Documents/TotalStationBT/

## 常見問題

**Q: 連線失敗**
- 確認藍牙已配對（系統層級）
- 確認儀器已進入通訊模式
- 部分儀器需先在儀器端「接受連線」

**Q: 資料顯示紅色（無法解析）**
- 使用「原始檔」匯出，確認原始格式
- 可自行擴充 `TotalStationParser.kt` 新增解析邏輯

**Q: Android 12+ 連線問題**
- 確認已授予 BLUETOOTH_SCAN 和 BLUETOOTH_CONNECT 權限

## 線段編輯（旋轉 / 平行拉伸）

在「2D 平面圖」畫面的選單開啟 **線段編輯模式**，即可對每一條線段做 CAD 式的手動編輯。

### 建立可編輯線段
- **由選取點建立線段**：在圖面依序點選 2 個以上點位 → 選單 →「由選取點建立線段」，可選折線或封閉多邊形。
- **由 DXF 圖元建立**：編輯模式下直接點選底圖的線／聚合線，確認後複製成可編輯線段（底圖本身不會被改動）。

### 三種手動編輯
| 模式 | 操作 | 行為 |
|------|------|------|
| 旋轉 | 按住線段拖曳 | 以「起點／中點／終點」為軸心轉動該段；鄰接線段共用接點自動跟隨。勾選「鄰線保持原方向」時，鄰線方向不變、接點以交點自動延伸 |
| 平行拉伸 | 按住線段往垂直方向拖曳 | 線段保持平行位移，**垂直方向的鄰線自動變長或縮短，接點依舊相連** |
| 接點 | 按住白色接點拖曳 | 單獨搬移接點，兩側線段跟著改變 |

- 拖曳過程即時顯示長度、方位角、位移量。
- 「數值」按鈕可輸入精確角度（°）或位移量（m）。
- 支援多步復原、線段成果表（各接點 E/N、每段長度與方位角、周長與面積）。
